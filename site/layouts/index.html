Architecture

{{ with resources.Get "images/architecture-flow.svg" }}{{ end }}
  1. Intake: Validate scope, author TaskContract, and compile trusted configuration.
  2. State: Reserve authority in the fenced SQLite StateStore before physical dispatch.
  3. Execute: Run isolated Pi adapter with optional System-One decision advisory.
  4. Verify & Gate: Bind independent check evidence to candidate digests and enforce authenticated gates.
  5. Publish & Compact: Reconcile external effect receipts and compact reviewed memory into CAS stores.
