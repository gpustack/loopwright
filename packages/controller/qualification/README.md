# Controller qualification boundaries

Ordinary controller/CLI tests use real Git, retained S02 and byte-verifier Workers without Docker or credentials.
Root test totals, static recipe compilation and copied-ledger controls do not establish native SDK or live-provider
acceptance. Native outcomes are recorded separately with their actual process, request, artifact and cleanup evidence.

The private delivery entrypoints are restricted to this approved local S04 program/worktree. The preflight issuer
cannot issue parent or application capability. The S04 native parent requires a live original reservation; its signed-meter child needs
the matching actual ledger owner and original registered signed one-use bootstrap channel. A flag, environment value,
copied fixture, manifest alone or saved dispatch marker cannot issue an execution meter or a product S02 permit.
Public product CLI/configuration has no fixture, activation, transport-bypass or arbitrary-module option.

The original parent reserves before work. Legacy counts, held caps and authenticated settled actual counts are
separate. The original time fence precedes preparation; unknown effects/ownership/cleanup/accounting block affected

registration, owner, exit and retained streams. Commit uncertainty remains fenced. Known settled failures permit a
relevant corrected run within the same remaining bounds. Never recover an old capability from its serialized files.

The image inspector reads a pinned Docker route and original raw archive without host extraction. It checks the
pinned OCI index/manifest/config identities, descriptor lengths/hashes, ordered layers/diffIDs and complete copied
payload. Only an unambiguous linux/arm64 image and explicitly associated supported attestation metadata are accepted;
attestation provenance remains NOT_VERIFIED. Source symlink mode is retained; Docker's Linux symlink mode0777 is
checked separately from host mode, with exact target and regular-file mode/uid/gid comparisons.

Selected immutable decoded data can be reused only after fresh archive parsing/diffID hashing and bytewise equality.

Configured JS heap and logical buffer bounds are distinct from observed RSS; no OS memory sandbox is claimed.
A source-binding refresh rehashes only changed source identities and requires the original expected bytes to still
match. It cannot silently replace the image expectation. All original failed expectations and snapshots are retained.

A passing fixed preflight establishes local image/daemon/payload/capability readiness only. Product native
cycle/repair/recovery, CLI/secret and final legacy Pi qualification remain separate obligations in the S04
specification. Controlled fixture provider replies are synthetic; live-provider qualification requires its own
separately authorized credential and execution scope.

Native delivery invokes the production CLI `main` with normal explicit `run` flags and `--json` in the original
owned Node child. Its awaited JSONL sink is observed without replacing controller/adapter ports or modifying CLI
source. A private outer cancellation signal follows the same real process signals; CLI retains its own production
signal controller. Only actual admission events open the existing private transport guards. API and CLI tests remain
separate evidence; this entry does not claim a separately spawned CLI process or live-provider results.

Retained candidate manifests and verifier parameters contain logical file references. The collector retains their
actual source blobs and Pi workspace/session captures, without treating logical paths as controller store filenames
or interpreting user file contents as storage references. Missing actual backing bytes still fail qualification.
